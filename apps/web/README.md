# app — Thumbs Up 프론트엔드

Next.js(App Router) · TypeScript · Tailwind CSS v4 · Biome · pnpm

## 실행

```bash
pnpm install
pnpm dev        # http://localhost:3000
```

## 품질 게이트

```bash
pnpm typecheck && pnpm lint && pnpm build
```
